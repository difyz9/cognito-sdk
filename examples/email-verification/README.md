# 邮箱验证码激活用户示例

本示例演示如何使用 AWS Cognito SDK 通过真实邮箱接收验证码并激活用户账户。

## 功能说明

这个示例展示了完整的用户注册和邮箱验证流程：

1. ✅ 用户输入真实邮箱地址
2. ✅ 用户设置登录密码
3. ✅ 调用 `SignUpUser` 注册新用户
4. ✅ AWS Cognito 自动发送验证码到邮箱
5. ✅ 用户查收邮件获取验证码
6. ✅ 用户输入验证码
7. ✅ 调用 `ConfirmSignUp` 激活账户
8. ✅ 验证后自动登录获取 Token

## 运行示例

```bash
cd examples/email-verification
go run main.go
```

## 使用流程

### 1. 运行程序

```bash
go run main.go
```

### 2. 输入真实邮箱

程序会提示你输入邮箱地址，请使用你能收到邮件的真实邮箱：

```
请输入您的真实邮箱地址: your-email@example.com
```

### 3. 设置密码

输入符合要求的密码（至少8位，包含大小写字母、数字和特殊字符）：

```
请设置登录密码（至少8位，包含大小写字母、数字和特殊字符）: YourPass@123
```

### 4. 等待验证码

注册成功后，程序会显示验证码发送信息：

```
✓ 注册成功!
UserSub: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
用户已确认: false

📧 验证码已发送:
   目标地址: y***@e***.com
   发送方式: EMAIL
   属性名称: email
```

### 5. 查收邮件

打开你的邮箱，查找来自 AWS Cognito 的验证邮件。邮件主题通常为：
- "Your verification code"
- 或其他根据你的 Cognito 配置设定的主题

邮件中包含6位数字验证码。

### 6. 输入验证码

在程序提示时输入收到的验证码：

```
请输入您收到的6位验证码: 123456
```

### 7. 完成激活

程序会验证邮箱并自动登录：

```
✓ 邮箱验证成功!

查看验证后的用户状态...
   用户状态: CONFIRMED ✅
   邮箱验证: true ✅
   是否启用: true

✓ 登录成功!

认证信息:
   AccessToken (前50字符): eyJraWQiOiJ...
   IDToken (前50字符): eyJraWQiOiJ...
   RefreshToken (前50字符): eyJjdHkiOiJ...
   过期时间: 3600 秒

✅ 完整流程完成!
用户已成功注册、验证并登录
```

## 注意事项

1. **真实邮箱**: 必须使用能正常接收邮件的真实邮箱地址
2. **验证码有效期**: AWS Cognito 发送的验证码通常有效期为24小时
3. **密码要求**: 
   - 至少8个字符
   - 包含大写字母
   - 包含小写字母
   - 包含数字
   - 包含特殊字符（如 @, #, $, % 等）
4. **邮件延迟**: 验证码邮件可能需要几分钟才能送达，请耐心等待
5. **垃圾邮件**: 如果收件箱没有，请检查垃圾邮件文件夹

## 相关方法

- `SignUpUser(email, password, phone)`: 注册新用户，触发验证码发送
- `ConfirmSignUp(username, code)`: 使用验证码确认注册
- `GetUser(username)`: 获取用户详细信息
- `Login(username, password)`: 用户登录
- `DeleteUser(username)`: 删除用户（测试用）

## 故障排查

### 验证码未收到

- 检查邮箱地址是否正确
- 查看垃圾邮件/促销邮件文件夹
- 等待5-10分钟再检查
- 检查 AWS Cognito 配置中的邮件设置

### 验证码验证失败

- 确认验证码输入正确（6位数字）
- 检查验证码是否过期
- 确认使用的是最新收到的验证码

### 密码不符合要求

确保密码包含：
- ✅ 至少8个字符
- ✅ 大写字母（A-Z）
- ✅ 小写字母（a-z）
- ✅ 数字（0-9）
- ✅ 特殊字符（@#$%等）

示例密码：`MyPass@123`
